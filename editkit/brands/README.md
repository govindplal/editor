# Creator / brand bibles

One file per creator, channel or brand you edit for repeatedly: `editkit/brands/<name>.md` (copy `_template.md`).
It is the style bible from the director's-brief pattern: rules that must survive every session, **pasted
verbatim into the plan, never paraphrased** (paraphrase causes drift).

- Read it when the user names the creator/channel/brand (or the upload is clearly theirs). It overrides
  STYLES.md defaults but not the user's request for this video.
- Create or update it when the user states a lasting preference ("always yellow keywords", "never use emojis",
  "my handle is @x"). Then merge it to main like any other global change.
- Keep it short (≤ 40 lines). It's rules, not history.
